# Astro Notes

Transcripts and study notes for the YouTube channel
[The Anchor Of Life With Brajesh Gautam](https://www.youtube.com/@theanchoroflife_brajeshgautam)
(Hindi and Hinglish talks on spirituality, astrology and self-inquiry).

## What is here

| Path | Contents |
|------|----------|
| `transcripts/` | One text file per video, 466 videos in total, about 7.2 million words |
| `INDEX.md` | Every video with its length, word count and YouTube link |
| `index.csv` | Same index as a spreadsheet-friendly file |
| `docs/` | Published notes site (GitHub Pages) |

Live notes: https://codersacademy006.github.io/astro-notes/

## Notes

Point-wise study notes are being written video by video. One sample is live so the
format can be reviewed before the rest are produced:

- [Ahankar ka Gorakh Dhandha](https://codersacademy006.github.io/astro-notes/notes/ahankar-ka-gorakh-dhandha.html)
  (timestamped sections, diagrams, tables, and a note wherever the speaker gives his own opinion)

## Transcript format

Each file starts with the title, video URL, duration and source, followed by paragraphs
of roughly 30 seconds each:

```
Title
https://www.youtube.com/watch?v=<id>
Duration: 116.8 min
Source: ...

[00:00:00] first paragraph
[00:00:31] second paragraph
```

## Accuracy

The transcripts are machine generated (Whisper large-v3-turbo) from the audio, and they
are not edited by hand.

- Repetition loops and hallucinated text, a common failure on long audio, were detected
  and re-transcribed, and a final scan found none left.
- Hindi words, names and Sanskrit terms can still be misheard. Check important quotes
  against the video using the timestamps.
- Three very short videos (`MtZAAD32Bn0`, `vbibl_RoDSw`, `AHjfxIiJY2Q`) have few words
  because the videos themselves are only seconds to a few minutes long.
- A few passages with music, chanting or silence produce little or no text.
